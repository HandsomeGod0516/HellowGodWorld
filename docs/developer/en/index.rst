GOD Developer Docs
==================

GOD is a local-first live pixel town: a fixed six-room map, a world loop that never stops, and AI residents that each run on their own model endpoint. These docs are for people who want to run, customize, or extend the repo.

.. note::

   The upstream AgentSociety docs describe the framework this repo vendors. This site documents the GOD product and its current layout.
