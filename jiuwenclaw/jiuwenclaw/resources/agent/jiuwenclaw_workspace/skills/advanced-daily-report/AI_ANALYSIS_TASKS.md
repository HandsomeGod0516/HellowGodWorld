# AI 智慧分析功能開發任務

## 專案概述

為日報生成器新增 AI 智慧分析能力，包括智慧摘要、明日計劃建議、工作模式分析。

## 需求確認

| 專案 | 確認內容 |
|------|----------|
| LLM 配置 | 使用 JiuwenClaw 配置的模型（glm-4.7） |
| 分析頻率 | 支援頁面配置（自動/手動按鈕） |
| 摘要位置 | 放在報告開頭 |
| 明日計劃 | 合併在建議章節中，結合今日資訊 |
| 資料範圍 | 分析近 7 天資料 |
| 輸出格式 | 富文字（Markdown） |
